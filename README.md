# Atividade---Refatorando-a-tabela

Vamos separar nossas classes em diferentes responsabilidades através do padrão de projetos Adapter.
🎯 Objetivo da Atividade
Crie a interface br.pucpr.table.TableData para representar os dados de uma tabela (TableData)
Refatore as classes UsersPrinter e PlanetasPrinter para ter uma única classe Table
A largura da coluna será dada pela largura do seu cabeçalho.
🛠️ Requisitos para Execução
Linguagem: Java 17 ou superior
